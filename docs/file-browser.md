# 文件选择窗口

启动器数据目录与 Java 程序选择窗口支持右键文件管理，界面沿用 Windows 95 风格。

| 操作 | 快捷键 |
| --- | --- |
| 复制 / 剪切 / 粘贴 | Ctrl+C / Ctrl+X / Ctrl+V |
| 重命名 | F2 |
| 新建文件夹 | Ctrl+Shift+N |
| 删除到回收站 | Delete |
| 刷新 | F5 |
| 全选 | Ctrl+A |

选中项目时可打开、复制、剪切、重命名和删除；空白区域可粘贴、新建文件夹和刷新。支持多选复制、剪切及删除，重命名一次处理一个项目。复制、剪切、粘贴使用 Windows 文件剪贴板，可与资源管理器交换本地文件和文件夹。

出现重名时可确认生成副本名称，原有项目不会被覆盖。文件夹不能粘贴到自身或其子目录。删除前确认移入回收站；回收站不可用时报告失败，不自动改为永久删除。文件操作在后台执行，期间选择窗口保持打开并暂时禁用操作，完成后重新读取目录。

文件夹选择窗口仅列出文件夹，Java 选择窗口列出文件夹、java.exe 和 javaw.exe。目录链接的复制会明确拒绝；普通目录内指向外部的链接不会被递归遍历。

## 验证范围

单元测试覆盖递归复制、移动、重命名、名称校验、重名不覆盖、同目录剪切粘贴、拒绝向自身或子目录粘贴、目录链接及别名路径边界，以及文件被独占占用时清理临时副本并保留源文件的只读属性。

JavaFX 交互探针使用临时目录验证右键菜单、快捷键、后台操作期间关闭拦截、回收站确认与取消；使用独立 AWT 文件剪贴板读写验证原生 CF_HDROP 互通，检查复制/剪切标记和过期任务不能覆盖新剪贴板内容。未进行真实磁盘间的大文件搬移性能测试。
