# 实例加载器版本修改

实例详情“加载器”右侧的“修改”按钮打开当前 Minecraft、当前加载器类型的兼容版本列表。
支持 Fabric、Forge、NeoForge 同类型升级、降级及同版本完整重装；原版、游戏运行中或其他任务执行中禁用按钮。
查询随窗口关闭而取消。在“修改加载器”窗口选择版本并点击“更改”后，直接开始处理并显示统一任务进度窗口，不再弹出“完整重装加载器”确认窗口。游戏版本、实例身份和名称不变。

原版客户端和描述统一存放在启动器根目录的 `baseVerisons/<游戏版本>/`，不再为它们占用 `game/versions` 中的额外文件夹；更换游戏目录不会改变该共享缓存位置。重装使用全新临时游戏根目录，只有原版客户端、原版描述及原版依赖可作为输入复制。
旧加载器描述、JAR、依赖列表、启动参数和处理器产物不会作为新安装输入。
重新执行现有加载器安装适配器；Forge/NeoForge 重新运行官方客户端处理器，Fabric 重新获取完整安装描述并安装依赖。
不重新下载不变的游戏资源。安装所需的 Java 按现有运行时管理逻辑选择。

全新安装和依赖准备成功后才提交文件与实例配置：

1. 检查实例及描述未发生外部修改，比较共享依赖的引用和内容。
2. 发布所需文件，备份即将替换的本实例独占缓存；其他实例引用的同路径文件若内容不同则拒绝覆盖。
3. 用完整新描述替换旧描述，保存实例登记；提交失败恢复文件备份、旧描述和旧登记。
4. 清理旧加载器已知且不再被任何本地版本描述引用的文件、空依赖目录和临时工作区。

相同内容的共享缓存文件不会重复覆盖，但会先在干净环境中完成新的安装，不能借此跳过加载器安装或处理器执行。
旧实例没有完整安装产物清单时，无法确认归属的缓存会保留，不通过清空公共 libraries 删除其他实例的数据。
新描述记录 `fuzzLoaderFiles`，包括安装器生成的专属文件与处理器依赖，便于后续准确清理。
回滚使用同盘重命名恢复备份，避免磁盘已满时再次分配完整文件；若回滚本身失败，会保留恢复文件并在错误提示中给出备份目录，绝不清理唯一备份。

存档、模组、用户配置、隔离设置、内存、Java 路径、自定义启动参数均保留；模组版本不自动升降级。
下载和处理阶段可取消；进入文件提交后不再接受取消或正常退出，避免产生半提交状态。现在另有磁盘恢复日志：替换文件前保存旧版本和预期新版本指纹，强制退出后在启动时提供恢复或清理选项；发生外部文件修改或备份损坏时停止自动恢复并保留记录。详见 [稳定性与恢复](stability.md)。

本地测试覆盖全新安装输入、升降级、已有目标缓存、用户数据和设置保留、取消、安装失败、提交失败回滚、共享引用与冲突保护。
JavaFX 测试覆盖原版禁用、查询并选择版本、确认与进度、提交期间防取消、界面更新、关闭查询窗口。
真实安装适配器的联网测试按 `fuzz.reinstallIntegration=true` 启用，并通过 `fuzz.reinstallLoaders` 选择加载器；不进行账号授权或游戏启动。

真实联网验证已完成：Fabric 0.20.1 → 0.20.0、Forge 1.21.1-52.1.20 → 1.21.1-52.1.19、NeoForge 21.1.265 → 21.1.264。
其中 Forge 和 NeoForge 于 2026-10-29 继续执行此前中断的验证并通过：完整运行官方安装适配器、检查依赖文件存在、版本登记更新、测试存档保留及临时安装目录清理。
这些验证不包含账号授权、游戏实际启动或模组兼容性检查。
同日执行 `./gradlew.bat test -Dfuzz.uiTests=true --console=plain`，96 项通过、0 项失败；2 项需要显式启用的联网测试在该轮跳过，加载器联网验证已单独运行并通过。

参考 [Prism 组件版本管理](https://github.com/PrismLauncher/PrismLauncher/blob/develop/launcher/minecraft/Component.cpp)。
