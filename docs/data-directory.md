# 默认数据目录

未配置数据目录时，启动器使用 exe 所在目录下的 `data`，启动时自动创建。
该目录保存设置、实例登记、账号、加密凭据、日志、皮肤缓存和 Java 运行时信息；游戏默认使用旁边的 `game`。
直接运行 jar 时使用 jar 所在目录，Gradle/IDE 开发时使用项目工作目录。

兼容顺序：测试/命令行的 `fuzz.dataDir` 覆盖 → 已保存的自选数据目录 → 已有本地 `data/settings.json` → 旧默认目录中的已有设置 → 新默认 `data`。
旧默认配置不会自动搬移；需要迁移时在设置中选择空的新数据目录，保存后沿用现有迁移与自动重启流程。
目录选择的稳定定位文件仍保存在原引导目录，防止已有自选目录在升级后失联；未配置自选目录的新启动器无需创建该文件。

回归覆盖本地默认路径、显式覆盖、自选目录及重启迁移、本地配置优先于旧默认配置、旧配置保留。
`data` 与 `game` 均不提交到 Git。
