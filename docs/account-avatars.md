# 微软账号头像

微软登录成功后保留官方 Minecraft 资料中的活动皮肤地址，后台下载官方纹理并合成脸部与帽子层，使用像素缩放显示。头像与纹理地址缓存位于启动器数据目录的 `skins/`，按账号 UUID 隔离；切换数据目录时一并迁移。

旧账号文件没有皮肤地址时，通过官方公开账号资料查询。重启优先复用有效缓存；再次登录后发现皮肤地址变化时更新缓存。退出登录或切换到离线账号后恢复默认头像；取消中的旧请求即使迟到也不会覆盖当前账号头像。网络、图片或缓存错误会记录到启动器日志，头像显示默认图标，不改变登录结果。

仅访问官方账号与纹理服务，不依赖第三方头像网站；解析图片前校验 PNG 大小和尺寸。兼容旧账号 JSON、64×64/64×32 皮肤和按比例放大的皮肤。

验证使用本地 HTTP 服务和合成测试皮肤，覆盖透明帽子层、旧版不透明帽子层、缓存复用、皮肤变更、非法图片、非法地址及数据目录迁移。JavaFX 测试验证头像绑定、退出重置和迟到响应保护；未在本次验证中操作用户的真实微软账号。
