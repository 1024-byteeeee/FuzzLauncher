# 验证记录

日期：2026-10-29。平台：Windows x64，构建 JDK 21，JavaFX 21.0.2。

## 实例管理、页面任务与数据目录

安装失败或取消时递归清理本次实例目录、临时工作目录和本次新增且未被已有实例引用的基础版本目录，不再保存 incomplete-profile 残留；已存在的实例、基础版本和公共依赖缓存保留。回归测试覆盖原版元数据失败、加载器中途取消、实例发布后取消、登记失败后的嵌套目录清理和成功安装后的临时目录回收。状态栏仅显示游戏运行/退出状态和退出码，不显示日志路径；异常提示仍可提供日志位置。

所有应用弹窗共用 Windows 95 标题栏、边框、图标和拖动逻辑，包括错误、确认、下载进度及文件/目录选择。JavaFX 交互探针验证确认/取消/关闭返回值、目录导航与选择、Java 文件选择和完整路径输入，并检查无系统装饰边框和统一图标；启动阶段尚无主窗口场景时也可显示错误弹窗。

单元测试验证实例完整删除、共享缓存保留、目录身份校验、磁盘刷新和手动删除后的登记同步；数据目录测试验证配置、账号凭据、日志迁移、原目录备份、占用与非空目标拒绝。

独立 JavaFX 交互探针使用临时数据和本地 HTTP 服务，验证切换页面取消游戏版本及加载器查询、旧响应不会覆盖新任务、下载进度弹窗、取消下载后重试，以及永久删除确认框的取消和确认分支。设置页验证保存数据目录后重启迁移、账号恢复和游戏根目录不变。以上没有使用用户游戏数据，也不代替真实 Minecraft 联网安装验收。

数据目录修改需选择空目录，保存后自动重启生效；旧数据保留备份，游戏目录及已下载 Java 的实际位置保持不变。默认目录保留一个指向新位置的引导文件。下载页面仅终止该页面发起的列表查询；安装继续由进度对话框管理。

自动重启额外验证开发环境 Java 启动和打包后的原生可执行文件启动：旧进程退出后，新进程完成目录迁移、持有新目录锁，账号和游戏根目录保留。窗口加载图标成功，并从打包 EXE 提取图标核对草地方块图案；ICO 包含 16–256 像素的多个尺寸。

## 按实例名隔离目录

验证旧 UUID 目录迁移后保留存档/模组/设置、中文和空格名称、重命名及仅大小写变化、重名/目录冲突拒绝、登记失败回滚，以及旧重名实例通过改名恢复。安装测试验证两个相同游戏版本、不同实例名称使用不同文件夹，实例名等于基础版本号时不会覆盖基础描述或 JAR。
本地 Java 子进程测试验证实际工作目录和启动 classpath 使用迁移后的名称目录。

## 下载性能与实例运行环境

实例内存分别持久化最小值和最大值，并用于 JVM 的 `-Xms`、`-Xmx`；验证保存/重读、重命名保留、非法范围和最小值大于最大值拒绝。旧配置沿用 256 MB 最小内存及原最大内存。按钮按下时保持两层边框和固定位置，仅切换凹陷颜色。

本地 HTTP 测试验证资源并发上限、已校验缓存不重复下载、中断后的 Range/If-Range 续传，以及服务器忽略 Range 时从头覆盖。保留镜像损坏后切换备用源和最终哈希验证测试。
界面验证手动输入 5000 MB、指定包含空格的 Java 路径、保存和重启恢复，以及另一实例保持原有 2048 MB 和自动 Java 配置。使用本地测试子进程验证指定 Java 路径和 5000 MB 启动设置。
这些验证不等于真实网络提速基准测试，也没有重新安装全部 Minecraft/加载器版本组合。
